# MATIN Watches

Website for MATIN Watches, built with Next.js (App Router) and TypeScript.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

Pushes to `main` deploy to Vercel.

## Site address (SEO)

Canonical links, the sitemap and Google product data use
`NEXT_PUBLIC_SITE_URL` (falls back to `https://matin-watches.vercel.app`).
When the real domain is live, set it in Vercel under
Settings > Environment Variables and redeploy.
